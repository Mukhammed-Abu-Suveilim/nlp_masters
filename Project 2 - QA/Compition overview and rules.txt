Overview
В задании даны обучающая и валидационная выборки, а также тексты для тестовой выборки. В рамках данного задания необходимо обучить модель машинного обучения на данном датасете, и залить полученные результаты в соревнование. Ваши результаты на публичной части теста будут отображаться на лидерборде. По результатам на закрытой тестовой выборке частично формируется оценка за домашнее задание.

Итоговый результат домашней работы состоит из двух частей:
Значение метрики лучшей из выбранных вами моделей на закрытом лидерборде после окончания соревнования.
Код для препроцессинга данных, обучения и запуска модели в одном файле. Код должен запускаться, быть воспроизводимым и отражать решение, отправленное на лидерборд.
Данные и модели:
Датасет прикреплен к соревнованию. Для обучения можно использовать дополнительные данные (но не тестовую выборку).
Можно использовать все модели, которые были пройдены на курсе до начала соревнования. Можно использовать локальные LLM модели до 1B параметров. Нельзя использовать LLM модели по API (т. е. GPT, Gemini, Claude, DeepSeek, etc.).
Evaluation
Решения оцениваются по exact match между предсказанным ответом и реальным ответом. То есть предсказанный ответ засчитывается как правильный при полном совпадении с реальным ответом.

Private leaderboard
В данном соревновании есть два лидерборда - публичный (открытый) и закрытый. Результаты моделей в процессе соревнования считаются на открытом сете, но финальные результаты считаются на закрытой части - будьте внимательны при обучении моделей и не переобучайтесь на лидерборд.

Бейзлайны
На лидерборде отображается несколько бейзлайнов - ряд из них дан для ориентира, другие задают пороги для оценок. Top-3 решения получают дополнительные баллы.

Submission File
Для каждого ID в тестовой выборке необходимо предсказать целевую переменную. Пример находится в sample_submission.csv

Files
train.csv - the training set
test.csv - the test set
sample_submission.csv - a sample submission file in the correct format
Columns
context - текст, в котором содержится ответ
question - вопрос, на который требуется ответить
answers - ответы
